# WebRecon Console

A lightweight JavaScript-based reconnaissance tool that runs directly in the browser console to help penetration testers, bug bounty hunters, and application security engineers collect application endpoints, API requests, parameters, and client-side security information during web application assessments.

---

## Overview

WebRecon Console hooks into browser networking APIs to capture application traffic generated by the web application. Instead of manually searching through hundreds of requests in the Network tab, the tool automatically records requests, summarizes discovered endpoints, extracts parameters, performs basic client-side security checks, and exports everything into a structured JSON report.

The tool is intended for use during authorized security assessments, penetration tests, and bug bounty engagements.

---

## Features

### Network Reconnaissance

- Capture all Fetch API requests
- Capture all XMLHttpRequest (XHR) requests
- Record HTTP methods
- Record requested URLs
- Capture request bodies
- Timestamp every request
- Automatically persist captured data across page reloads using Session Storage

---

### Endpoint Discovery

- Enumerate discovered endpoints
- Group identical endpoints
- Extract query parameters
- Extract POST body parameters
- Track the pages where each endpoint was discovered
- Build a clean endpoint summary

---

### Request Filtering

Automatically removes common third-party tracking requests including:

- Google Analytics
- Google Tag Manager
- Microsoft Clarity
- Facebook Pixel
- HubSpot
- Bing Analytics
- LinkedIn Pixel
- Segment
- Sentry

This helps focus only on application-related traffic.

---

### Client-Side Security Checks

The tool performs several basic client-side security checks including:

- JavaScript-readable cookies
- Local Storage enumeration
- Session Storage enumeration
- Detection of potentially sensitive storage keys

Examples:

- token
- jwt
- auth
- password
- api_key
- secret
- session

The tool also checks for:

- Mixed HTTP content on HTTPS websites

---

### Automatic Lazy Loading Detection

Includes an auto-scroll function that helps trigger:

- Infinite scrolling
- Lazy-loaded API calls
- Dynamic content requests

This improves endpoint coverage during reconnaissance.

---

### Report Generation

Generate a complete JSON report containing:

- Target information
- Captured requests
- Endpoint summary
- Request parameters
- Security findings
- Application requests
- Raw requests
- Notes for manual verification

The report is automatically downloaded from the browser.

---

## How It Works

The script works by monkey-patching:

- `window.fetch`
- `XMLHttpRequest`

Every captured request is stored in memory and periodically saved into Session Storage. After browsing the application, a report can be generated with a single function call.

## Usage

### Step 1

Open Developer Tools.

```
F12
```

or

```
Ctrl + Shift + I
```

---

### Step 2

Open the **Console** tab.

---

### Step 3

Paste the script into the console and press Enter.

---

### Step 4

Browse the application normally.

Visit as many pages as possible.

Log in if necessary.

Trigger different application functionality.

---

### Step 5

(Optional)

Run:

```javascript
autoScroll()
```

to trigger lazy-loaded requests.

---

### Step 6

Generate the report.

```javascript
reconReport()
```

A JSON report will automatically download.

---

### Step 7

To begin testing another target:

```javascript
clearReconData()
```

## Limitations

- Does not capture requests made before the script is injected.
- Hooks must be re-injected after a full page navigation.
- Cannot view HttpOnly cookies.
- Cannot read HTTP response headers due to browser security restrictions.
- Does not replace a proxy such as Burp Suite or OWASP ZAP.
- Designed for client-side reconnaissance only.
